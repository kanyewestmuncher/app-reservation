# app-reservation
# Nom de l'application: ReClass

Projet conçu en équipe avec : [Joseph Karib]

## Le problème

- Problème : Élèves qui oublie leur numéro de DA, avoir une fonction ``in app`` pour la réservation
- Persona : Jeremy, élève qui vient de commencer le cegep, connait pas le numéro de DA, pas habile avec les dépôts teams.

## La solution

- Proposition de valeur : Meilleur puisque ça évite d'avoir des réservations multiple sur le canal général (ce qui peut mélanger ceux qui gère le canal), avec cette appli, ça permet à l'élève d'être directement signed in dans l'application et quand qu'ils font leur réservation, le technicien reçoit une notification et prépare le matériel. Quand c'est prêt, l'élève reçoit une notification provenant de l'application.
- 
- Fonctionnalités du MVP :
- 
    En tant qu’élève, je veux me connecter automatiquement afin de ne pas avoir à entrer mon numéro de DA.
En tant qu’élève, je veux réserver du matériel afin de pouvoir l’utiliser sans passer par teams.
En tant que technicien, je veux recevoir une notification lorsqu’une réservation est faite afin de préparer le matériel.
En tant qu’élève, je veux recevoir une notification lorsque mon matériel est prêt afin de savoir quand le récupérer.
En tant que technicien, je veux voir et gérer les réservations afin d’organiser la préparation du matériel.
